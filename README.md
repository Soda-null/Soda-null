# Hi, I'm Young (李杨) 👋

**English** · [中文](#中文)

I'm a third-year mechanical engineering student at ZJUI, the joint institute of Zhejiang University and UIUC. This year I'm on exchange at UIUC. Still figuring out robotics, one project at a time.

## How I got here

I started with hardware: a machine that imitates how the gut moves, then soft pumps and artificial muscles, mostly with Arduino, STM32 and a lot of wiring. Later I got curious about the software side and moved on to robot simulation and learning.

These days I study how AI models and robots react when a person's household instruction is wrong.

## Things I've made

**Robots and hardware**

- [Ant-residual-rl-lab](https://github.com/Soda-null/Ant-residual-rl-lab): teaching a simulated four-legged robot to walk. The failed attempts are written down too.
- [Arm-manipulation-lab](https://github.com/Soda-null/Arm-manipulation-lab): robot arm math, built step by step, from kinematics to MuJoCo simulation.
- [artificial-muscle-testbench](https://github.com/Soda-null/artificial-muscle-testbench): CAD files for a rig that tests pneumatic artificial muscles.
- [Wearable-Iron-man-glove](https://github.com/Soda-null/Wearable-Iron-man-glove): a wearable forearm armor, modeled in CAD and split into parts for 3D printing. Yes, I watched the movies.

**Small tools and side projects**

- [whale-be-friends](https://github.com/Soda-null/whale-be-friends): Dafeiyu, an AI friend on WeChat. She remembers, she forgets, she writes a diary, and she loves plain white rice. 🐋
- [multi-agent-repo-protocol](https://github.com/Soda-null/multi-agent-repo-protocol): rules and scripts that stop several AI coding agents from overwriting each other in one git repo. I needed it because mine kept doing that.
- [grainger-studytrack](https://github.com/Soda-null/grainger-studytrack): a Mac study timer for the UIUC Grainger Engineering Library. It only counts when you are really there and really working.

## 中文

你好，我是李杨，浙江大学和 UIUC 联合学院（ZJUI）机械工程专业大三学生，这一学年在 UIUC 交换。机器人这条路还在一个项目一个项目地摸索。

**怎么走到这儿的：** 一开始做硬件：一台模拟肠道运动的装置，然后是软体泵和人工肌肉，主要是 Arduino、STM32 和一堆线。后来对软件那边好奇，就转去做机器人仿真和学习。现在在研究家务场景里，人给的指令有错时，AI 模型和机器人会怎么反应。

**做过的东西：**

- [Ant-residual-rl-lab](https://github.com/Soda-null/Ant-residual-rl-lab)：教仿真里的四足机器人走路，失败的尝试也都记下来了。
- [Arm-manipulation-lab](https://github.com/Soda-null/Arm-manipulation-lab)：一步步搭机械臂的数学和控制，从运动学做到 MuJoCo 仿真。
- [artificial-muscle-testbench](https://github.com/Soda-null/artificial-muscle-testbench)：气动人工肌肉测试台的 CAD 文件。
- [Wearable-Iron-man-glove](https://github.com/Soda-null/Wearable-Iron-man-glove)：可穿戴前臂装甲，用 CAD 建模，再拆成零件 3D 打印。没错，电影我看过。
- [whale-be-friends](https://github.com/Soda-null/whale-be-friends)：大肥鱼，住在微信里的 AI 朋友。会记事，会忘事，会写日记，最爱吃白米饭。🐋
- [multi-agent-repo-protocol](https://github.com/Soda-null/multi-agent-repo-protocol)：防止几个 AI 写代码助手在同一个 git 仓库里互相覆盖的规则和脚本。
- [grainger-studytrack](https://github.com/Soda-null/grainger-studytrack)：UIUC Grainger 工程图书馆的 Mac 学习计时器，人真的在、真的在学才计时。

**不搞机器人的时候：** 听中文、日文和英文歌，看利物浦（我是球迷），到处旅游，吹长笛。
